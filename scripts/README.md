# Скрипты Gigabyte VPN

## `add-node.sh` — добавление новой ноды

Поднимает новый сервер, **клонируя все настройки с существующего**: панель 3x-ui той же
версии, настройки (порты, `subPath`, `basePath`, xray-шаблон с маршрутизацией/DNS/цепочками),
системный тюнинг (BBR+fq+TFO, UFW, fail2ban, автообновления), cron и TLS-сертификат.

Клиенты **не копируются** — нода стартует пустой, под новых пользователей.

### Новый РУ-вход (расширение)

```bash
./scripts/add-node.sh entry \
  --ip 1.2.3.4 \
  --pass 'ROOT_ПАРОЛЬ_ОТ_ХОСТЕРА' \
  --domain vpn2.gigabytebot.com
```

**Перед запуском:** создайте A-запись `vpn2.gigabytebot.com → 1.2.3.4`
(Cloudflare — обязательно **DNS only**, серое облако). Скрипт это проверит.

По завершении печатает готовые значения для админки бота (Серверы → +).
Цепочки на европейские выходы клонируются с эталона — новая нода сразу умеет
ходить во Францию/Финляндию.

### Новый европейский выход

```bash
./scripts/add-node.sh exit --ip 5.6.7.8 --pass 'ROOT_ПАРОЛЬ'
```

Генерирует **свежие Reality-ключи** и печатает готовый JSON-блок outbound'а,
который нужно добавить в xray-шаблон входной ноды (плюс новый inbound и правило
маршрутизации).

### Опции

| Опция | Назначение |
|---|---|
| `--source <alias>` | эталон для клонирования (по умолчанию `moscow` для entry, `france` для exit) |
| `--key <path>` | публичный ключ для новой ноды (по умолчанию `~/.ssh/id_ed25519.pub`) |

### Требования
- `sshpass` на маке (`brew install sshpass`)
- SSH-доступ по ключу к эталонному серверу (алиасы в `~/.ssh/config`)
- Свежая Ubuntu на новой ноде, root-пароль от хостера

## Ещё быстрее: снапшот у хостера

Aeza (и большинство хостеров) умеют делать **снапшот/образ** сервера. Тогда:

1. Снять снапшот текущего входа/выхода.
2. Развернуть из него новый VPS — настройки идентичны «из коробки».
3. Догнать уникальное: домен + сертификат + свежие Reality-ключи + очистить клиентов.

Это буквально пара кликов в панели хостера. Скрипт выше нужен, когда снапшота нет
или нода у другого провайдера.
