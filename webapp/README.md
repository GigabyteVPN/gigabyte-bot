# Gigabyte — Telegram Mini App

Веб-апп для бота Gigabyte. Полный функционал бота в интерфейсе в стиле iOS:
покупка и продление подписок (Telegram Stars / USDT / USDC), пробная неделя,
промокоды, тикеты поддержки, запросы стран, история платежей с чеками и
полноценная админ-панель.

## Архитектура

- Фронтенд **не обращается к базе данных напрямую** — только к REST API бота
  (`../webapp_api.py`). Никаких ключей Supabase во фронтенде нет.
- Авторизация: каждый запрос несёт заголовок `Authorization: tma <initData>`;
  бэкенд проверяет HMAC-подпись initData токеном бота. Подделать её нельзя.
- Оплата Stars: API создаёт invoice-ссылку, веб-апп открывает её через
  `tg.openInvoice`, провижининг выполняет штатный обработчик бота.
- Оплата криптой: API выдаёт кошелёк/сумму/контракт, пользователь отправляет
  TXID, транзакция проверяется на Arbitrum через Alchemy.

## Разработка

```bash
# 1. Запустить бота локально (API поднимется на :8080)
cd .. && python bot.py

# 2. Запустить фронтенд
npm install
npm run dev            # http://localhost:3000, /api проксируется на :8080
```

Открывать интерфейс нужно из Telegram (initData подписывается Telegram-ом).
Для быстрой проверки вне Telegram API вернёт 401 — это ожидаемо.

## Сборка

```bash
npm run build          # → dist/, бот раздаёт его по /app/
npm run lint           # проверка типов
```

В Docker сборка происходит автоматически (первая стадия Dockerfile).

## Подключение к боту

В `.env` бота добавьте:

```env
WEBAPP_URL=https://ваш-домен.com/app/
```

Бот при старте настроит кнопку меню на мини-апп.
